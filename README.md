# MAVILIVE Bodycam

Upload these files to the same folder:
- index.html — online Player/Department editor and URL generator
- bodycam.html — clean transparent OBS overlay

Open index.html on your hosted site, enter Player Name and Department, then click GENERATE OBS URL and COPY OBS URL.

Example:
https://YOUR-SITE/bodycam.html?player=Mavi&department=Police

If Department is blank, the overlay displays CIVILIAN.

OBS:
Sources > Browser > URL = generated URL
Recommended size: 1920x1080
No custom CSS required.
